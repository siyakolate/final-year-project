# 🌿 Lakshmi Ayurvedic – Herbal Store Website

A full-stack web application developed to provide an online platform for Lakshmi Ayurvedic, enabling users to explore Ayurvedic medicines, view product details, and interact with the organization through enquiry and feedback features.

---

## 🚀 Features

- 🧾 Display of Ayurvedic medicines and herbal products  
- 📩 Customer enquiry system  
- ⭐ Feedback submission  
- 🔐 Admin panel for managing products and content  
- 📱 Responsive design (mobile + desktop)  

---

## 🛠️ Tech Stack

**Frontend:** React JS, HTML, CSS, JavaScript  
**Backend:** Spring Boot  
**Database:** MySQL
